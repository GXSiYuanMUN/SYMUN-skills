# 像 MXY.jr 那样写公文

本技能蒸馏自本技能作者（MXY.jr）主笔的「广西·思源模拟联合国大会」公文：**第二、三、四、六届**的邀请函与秘书长致辞，以及**第三至六届**的活动方案。

> ⚠️ **作者归属**：第五届的邀请函与秘书长致辞由该届秘书长撰写，第五届学术总监致辞由该届学术总监撰写——**均非本技能作者的作品，已排除在本技能之外**。第五届的**活动方案**由本技能作者主笔，其主题凝练与议题阐释仍是有效样本。

**核心信念**：本技能作者的公文之所以有辨识度，不在于辞藻，而在于一套稳定的**「主题—时代—青年」三元咬合结构**，和一套高度统一的**句法与意象系统**。二者缺一，文章就只是"合格的公文"；二者齐备，才是"像 MXY.jr 写的"。

## 使用前提（必读）

### 第一步：索要主题

本技能的一切从**主题**出发。开始写作前，必须确认以下信息：

| 必需项 | 说明 | 缺失时怎么办 |
|---|---|---|
| **大会主题** | 本届的主标题（最好带副标题） | **必须先问用户**，不得自行臆造主题 |
| 届次与年份 | 如"第七届，2027 年" | 可从主题语境推断，但要向用户确认 |
| 公文类型 | 活动方案 / 邀请函 / 秘书长致辞 / 背景文件 / 其他 | 若用户未指定，按下方"体裁路由表"选择 |
| 篇幅与交付格式 | 多少字、输出 .md 还是 .docx | 默认 .md，用户要 Word 则改用 `workbuddy-docx` 技能 |

> 🔴 **绝不跳过这一步。** 本技能作者每一届主题都是不同的，且主题决定了后面所有的时事选择、议题安排和价值落点。拿到主题之前动手写，等于蒙着眼睛造文章。

若用户只给了一个模糊方向（例如"写个关于全球治理的邀请函"），按下方「主题凝练法」先产出 2–3 个候选主题供用户选择，不要直接开写。

## 技能的两大板块

本技能由两大板块构成，使用时按顺序执行：

### 板块一：写作能力（做什么）

解决"写什么、怎么组织"的问题。详见 `references/01-写作能力.md`。

1. **主题凝练法**——从时代矛盾中提炼大会主题，含三种已验证的主题句式模型
2. **主题与议题的契合逻辑**——每个会场议题如何回扣主题、如何排列成"历史—当下—未来"链条
3. **权威时事检索与结合**——去哪查、查什么、怎么嵌进去（含权威信源清单与检索式模板）
4. **篇章结构**——活动方案九部分、邀请函五段式、致辞五段式的骨架

### 板块二：文风基因（怎么写）

解决"怎么说话"的问题。详见 `references/02-文风基因.md`。

1. **语气定位**——"有节制的激情"：激情在动词与意象里，不在感叹号里
2. **句法节奏**——长短句配比、四字格密度、三分句式、递进与转折的固定搭配
3. **意象系统**——节气/时令、古典意象、地缘意象、思源专属意象
4. **引证方式**——领导人论述、外长记者会、秘书长引语、经典文辞的四级引证表
5. **高频句式模板**——可套用的句式骨架库
6. **禁忌清单**——本技能作者**不写**的东西（比"写什么"更重要）

## 标准工作流（五步）

```
① 索要主题 → ② 拆解主题 → ③ 检索时事 → ④ 搭建骨架 → ⑤ 填充文风 → ⑥ 自检
```

### ① 索要主题
按上表确认主题、届次、体裁、篇幅。

### ② 拆解主题
读 `references/01-写作能力.md` 的「主题三问」，对给定主题回答三个问题：

- **主题的历史坐标**：这个主题指向哪一年、哪场会议、哪个历史事件？（本技能作者第六届主题锚定第 80 届联大与"十五五"规划建议，第五届锚定四中全会与第 80 届联大）
- **主题的现实矛盾**：当下国际社会最尖锐的那个具体问题是什么？（不是"全球形势严峻"，而是"发展中国家制造业薄弱、发达国家贸易壁垒高筑、后疫情时代经济复苏乏力"）
- **主题的落点人群**：最后落到谁身上、他们要获得什么？（本技能作者永远落在"处于人生关键节点的高中生"+"四个自信"+"规划人生航向"）

拆解结果写进草稿的隐含结构，不单独成节。

### ③ 检索时事（不可跳过）
读 `references/01-写作能力.md` 的「时事检索与结合」一节。按其中的**权威信源清单**和**检索式模板**实际执行检索，优先取：

- 权威机构官网原始表述（联合国、UNEP、人居署、世界银行、各国部委）
- 领导人讲话原文与外长记者会实录（新华社/外交部官网）
- 当年政府工作报告、中央全会文件

**硬性要求**：文中引用的每一个数据、每一句领导人论述、每一份文件名称，都必须来自实际检索到的材料，标注来源与年份。**不得凭记忆或想象编造引文。** 检索不到就明确说明"此处缺资料"，而不是编一句似是而非的话。

### ④ 搭建骨架
按体裁路由表选骨架（见 `references/01-写作能力.md` 末节"体裁路由表"），先写小标题和每节的要点占位，再填内容。

### ⑤ 填充文风
读 `references/02-文风基因.md`，逐句过一遍句法、意象、引证、禁忌四项。**初稿写完后必须回头重写一遍**，把不合文风的句子改掉——这是本技能作者文本与公文模板之间真正的分水岭。

### ⑥ 自检
运行风格自检脚本：

```bash
# 路径按技能实际安装位置调整
python <skill目录>/scripts/style_check.py <稿件路径>
```

脚本检测：感叹号密度、网络用语、四字格密度、引证密度、平均句长、被动句、禁用词、段落长度、结尾格式。**按报告逐项修正**，不要只跑不改。

## 体裁路由表

| 用户需求 | 体裁 | 骨架 | 篇幅 | 关键特征 |
|---|---|---|---|---|
| 活动方案、申请文件、报团委的正式文件 | 活动方案 | 九部分（见 references/01） | 8000–20000 字 | 第二部分是灵魂，第五部分"大会目的及意义"用"战略掣领／战术精微"双层结构 |
| 邀请学校参会、发给友校社团 | 邀请函 | 五段式 | 700–1100 字 | 开篇必写节气时令；结尾必写"敬请光临" |
| 开幕式/闭幕式发言、寄语 | 秘书长致辞 | 五段式 | 800–1200 字 | 引证密度最高；结尾落款"大会秘书长 本技能作者 + 日期" |
| 会场背景文件、议题背景 | 背景文件 | 四段式 | 4000–20000 字 | 学术本位，重数据与制度史；结尾给"代表提示" |
| 报名通知、招募公告 | 通告 | 表格为主 | 视情况 | 口语化一档，节奏更快，诗化引用减量 |

## 贯穿全程的铁律

1. **主题先行。** 没有主题不写稿；主题没想清楚不写稿。
2. **引证必有源。** 所有引文、数据、文件名称，均须来自实际检索，每处标注来源与年份。
3. **激情有节制。** 本技能作者的稿子**通篇没有一个感叹号**。情绪靠动词、意象和排比承载。
4. **青年是终点。** 任何宏大叙事，最后一段必须落到具体的、可行动的青年责任上。
5. **三层咬合。** 主题、时代、青年三者必须互相咬住，不能各说各话。
6. **改一遍再交。** 写完初稿后重写一遍，去除所有"公文腔"惯性表达。
