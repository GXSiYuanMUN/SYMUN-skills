# 板块一：写作能力

本文件回答"写什么、怎么组织"。文风部分见 `02-文风基因.md`。

---

## 一、主题三问（凝练法的核心）

蒙贤熠每届大会主题的凝练，都可还原为三次提问。按顺序问，答案就是主题的骨架。

### 问一：主题的历史坐标在哪？

蒙贤熠的主题从不是凭空铸造，而是**挂靠在一个已经存在的重大节点上**：某届联大主题、某个周年纪念、某次会议召开、某份中央文件。

历届实证：

| 届次 | 主题 | 挂靠的坐标 |
|---|---|---|
| 第三届（2025.1） | 同探历史经纬，齐迎时代挑战，共话发展未来 | 习近平 APEC/G20 "南方时刻"外交、中非合作论坛北京峰会 |
| 第四届（2025.8） | 重温联合国创始初心，构建共商共建共享体系：联合国成立80周年背景下的多边合作与机制革新 | 联合国成立 80 周年、抗战胜利 80 周年、王毅慕安会"中国专场" |
| 第五届（2026.2） | 前路弗迷：加速变革我们的世界 | 二十届四中全会"十五五"规划建议、第 80 届联大主题"携手共进" |
| 第六届（2026.8） | 奇点时刻：迈向新时代的全球治理 | 第 80 届联大"携手共进"、十五五规划建议、慕安会王毅演讲 |

> 📌 **六届的主题凝练全部出自蒙贤熠主笔的活动方案**——包括第五届。第五届的邀请函与致辞由罗立茜撰写，但主题"前路弗迷"是蒙贤熠在方案中定的。

**操作**：给定主题后，先回答"这个主题回应的是哪一件正在发生的事？"答不上来的主题，说明它没有根，是空词。

### 问二：主题要解决的现实矛盾是什么？

蒙贤熠从不写"世界面临百年未有之大变局"这种正确但空的判断，他一定落到**三到四个具体的、可枚举的困难**上。

第六届方案的写法（原文照录）：

> 当前，全球发展仍面临多重挑战：发展中国家制造业薄弱、发达国家贸易壁垒高筑、后疫情时代经济复苏乏力，地缘冲突与国际信任赤字更让局面雪上加霜。但一个和平、公平、可持续的世界不应有人掉队。

**句式模板**：
> 当前，{领域一}仍面临{问题一}、{领域二}仍面临{问题二}、{领域三}仍面临{问题三}，{时代性危机}更让局面雪上加霜。

三个困难必须是**不同领域**的（经济/政治/技术/生态/安全），不能是同义反复。

### 问三：最后落到谁身上？

蒙贤熠的落点从来不是"全世界"，永远是**一个具体的、有身份的年轻人**，且必须给出**具体的行动项**。

第六届原文：

> 本次活动旨在带领处于人生关键节点的高中生，以全新视角审视"社会发展""国家构建""全球化"与"全球治理"彼此之间的深层联系，在思考中深刻感悟中国减贫事业的伟大意义、社会主义制度的显著优越性与中国式现代化的丰富内涵，砥砺为民族复兴中国梦奋勇前行的初心。

**落点三要素**：① 身份（"处于人生关键节点的高中生"）② 视角（"以全新视角审视……之间的深层联系"）③ 行动（"砥砺……初心""规划人生航向"）。

## 二、主题句式模型（三种，均有历届实证）

### 模型 A：三段式排比 —— "同探历史经纬，齐迎时代挑战，共话发展未来"

适用：历史与现实并重、需要同时照顾多个会场主题的场合。

公式：`动词+名词（历史维度），动词+名词（现实维度），动词+名词（未来维度）`

三个分句分别对应三个会场或三层议程，句式平行，动词统一。

### 模型 B：引号式双层 —— "重温联合国创始初心，构建共商共建共享体系：……背景下的多边合作与机制革新"

适用：需要给主题加限定范围、防止发散的场合。

公式：`{大方向A}，{大方向B}：{限定范围}背景下的{具体议题1}与{具体议题2}`

冒号前是价值主张，冒号后是学术落点。冒号是必需的——它把宏大叙事钉在具体议题上。

### 模型 C：隐喻式点题 —— "前路弗迷：加速变革我们的世界" / "奇点时刻：迈向新时代的全球治理"

适用：主题需要单独提炼、需要留下记忆点的场合。

公式：`{隐喻性四字或六字短语}：{对隐喻的展开说明}`

- "前路弗迷"化用毛泽东"愿苍生俱饱暖，不辞辛苦出山林"之外的传统表达，指方向感与定力
- "奇点时刻"取自物理学"奇点"，指旧秩序崩塌、新秩序萌生的临界状态

**主标题控制在 12 字以内**，副标题承担全部解释功能。

## 三、议题如何与主题契合（这是全篇最见功力的地方）

蒙贤熠的议题不是"凑够几个会场"，而是**主题的三个切面**。逐届拆解：

### 3.1 契合的三种模式

**模式一：历史—当下—未来链条**

第三届：「萨赫勒地区治理」（当下）＋「1787 年费城制宪」（历史）—— 一个跳到未来，一个回到过去，互补。
第五届：方案明确写"三个中文会场与一个主新闻中心形成了'历史－当下－未来'的完整逻辑链：第一会场回溯1955年万隆会议，溯源全球南方团结的历史根基；第二会场聚焦联合国内部机制革新；第三会场则落脚21世纪新兴互联网技术背景下的餐饮配送行业发展"。

**模式二：同一主题的三个层级**

第四届：宪章精神（旧金山会议）→ 机制革新（联合国改革）→ 具体实践（叙利亚危机、全球毒品）—— 从制度源头到机制改良到议题落地。

**模式三：主副双线**

第六届：主线是"非正规住区改造"（当下、具体、有争议），副线是"申根协定的起草与签署"（历史、程序性、可推演）。一实一虚，同属"人类面对跨境/跨界治理难题"。

### 3.2 每个议题的阐释三段式（必用）

蒙贤熠为每个会场议题写的阐释，固定三段：

```
（1）历史演进与治理形势   —— 用具体年份、具体人物、具体场景把议题"落地到画面"
（2）本议题旨在……        —— 一段话讲清"通过这个议题，代表要理解什么"
（3）议题设置的考量与价值  —— 讲清"为什么用这个会场机制来讨论，而不是别的机制"
```

第三段是蒙贤熠的独创，示范如下（第六届申根会议）：

> 在模拟联合国的机制框架下，聚焦"申根协定"的创制过程，具有考量与独特的教育价值。
> 区别于传统外交模拟，本次会议的参与者并非在既定规则下进行演绎，而是置身于规则诞生的原点。**视角的前移**使得讨论不再局限于法律条文的适用，而是切实聚焦于"是否要取消公民边境检查""外国人如何在申根领土内自由通行"、"安全缺口如何弥补"以及"时间表如何设定"等根本性问题。代表们得以暂时搁置对现有申根体系的评判，转而直面自由与安全这一最尖锐的矛盾，通过创造性的谈判与妥协，共同探索制度构建的初始路径。

**"区别于……区别在于……视角的X使得……"** 是这一段的固定句式，务必掌握。

### 3.3 议题背景的收束句（每场必写）

每段议题阐释末尾，蒙贤熠都会用一个"……本议题旨在……"的排比长句收束，把议题拉回代表的身份责任：

> 本议题旨在推动全球城市正视这一治理痛点，超越传统国际博弈的思维定势，探索务实可行的合作路径；**同时**，引导代表深入洞察城市化进程背后的社会公平议题，使其在"百年未有之大变局"的时代背景下，通过沉浸式的政策实践体验，深刻思考城市治理者应当肩负的责任与使命。

公式：`本议题旨在{面向世界层面的意义}；同时，引导代表{落到代表个人层面的意义}。`

## 四、时事检索与结合（不可跳过）

### 4.1 为什么必须检索

蒙贤熠的稿子之所以"厚"，在于**每一届都重新做了一遍当年的一手资料工作**。他引用的材料有明确的类型和出处，读者能顺着查下去。不检索就写，稿子会立刻塌成"万能模板"。

### 4.2 权威信源清单（按类型）

| 类型 | 具体来源 | 用途 |
|---|---|---|
| 中国最高权威 | 中国政府网 gov.cn、新华网 news.cn、人民日报 people.com.cn | 政府工作报告、中央全会文件、领导人讲话原文 |
| 外交口径 | 外交部 mfa.gov.cn、外交部发言人答问、记者会实录 | 外长记者会引语（蒙贤熠高频使用"今年三月，王毅外长在第十四届全国人大三次会议外交主题记者会上表示"） |
| 联合国系统 | un.org、UNGA 决议与主题、UN News | 联大主题、秘书长表述、机构报告 |
| 议题专门机构 | UN-Habitat（人居署）、世界银行、UNEP、WHO、UNCTAD | 议题背景的硬数据（第六届用了人居署的"超过10亿人口栖身于非正规住区"） |
| 学术与智库 | 各国智库报告、知名期刊、学术机构官网 | 背景文件深度部分 |
| 地方 | 广西壮族自治区政府网 gxzf.gov.cn、柳州市政府网 liuzhou.gov.cn | 北部湾战略、平陆运河、本地经济数据 |
| 历史文献 | 联合国宪章原文、维基百科（仅用于线索，不直接引） | 历史会场背景 |

### 4.3 检索式模板（照此构造查询）

```
# 拉取某届联大/UN 主题
<年份> 联合国大会 主题 第80届 携手共进

# 拉取某次会议官方表述
<年份> <机构名> 报告 <议题关键词> 数据 site:un.org

# 拉取领导人讲话原文
<年份> <领导人姓名> 讲话 全文 <场合> site:gov.cn

# 拉取外长记者会
<年份> 王毅 外交主题记者会 实录

# 拉取当年政府工作报告
<年份> 政府工作报告 全文

# 拉取历史会场档案
<年份> <历史事件名> 条约 原文 起草过程 谈判
```

### 4.4 结合的六种手法

蒙贤熠把时事嵌进文章，用的是这六种具体手法：

**手法 1｜开篇定位法** —— 用当年最高规格的外交场面定调。
> 2026 第六届……高举习近平新时代中国特色社会主义思想伟大旗帜，贯彻《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》精神，呼应第 80 届联合国大会"携手共进：促和平、发展、人权八十载，继往开来，再谱新篇"之号召，设定主题为……

**手法 2｜领导人引证法** —— 引具体会议、具体场合、具体原话。
> 习近平总书记在党的二十大报告中殷切勉励青年群体，指出新时代青年是推进中国式现代化建设的关键力量……

**手法 3｜数据锚定法** —— 用一个具体数字把宏观叙事压到实地上。
> 据联合国人居署统计数据显示，全球目前有超过 10 亿人口栖身于非正规住区或贫民窟……

**手法 4｜"我写的是现在"法** —— 把议题放在当下进行时。
> 1991 年 12 月 25 日，红旗从克里姆林宫上空黯然降下。"冷战"结束，雅尔塔体系终结，世界进入"一超多强"时代。但 2026 年的今天，美国的颓态已开始显现，旧的世界秩序亟需重构。

**手法 5｜地方嫁接法** —— 把全国叙事落到家乡。
> 柳州位于国家"北部湾战略"枢纽地带……广西作为"中国——东盟"交流与合作的关键平台，正在成为我国新的重要对外窗口，平陆运河的建设将为广西未来 30 年乃至更远的一段时期的发展奠定新的基础。

**手法 6｜青年回扣法** —— 每段宏大叙事的最后一句落到青年。
> 期望与广西中学生一道，在模拟联合国这一独特平台上，让青年在学习 2026 年两会精神、关注祖国发展的过程中，接触"全球治理"，进一步认识中国在世界中的位置，坚定"四个自信"、更好地规划人生航向。

### 4.5 引证的三条纪律

1. **标全称与年份。** 写"习近平总书记在党的二十大报告中指出"，不写"习主席曾指出"。写"第十四届全国人大三次会议外交主题记者会上"，不写"今年三月"。
2. **引原话加引号。** 引了就要用引号原文呈现，不转述不留出处。
3. **每次发文前重新检索。** 上一届引过的，这一届未必还能用；领导人职务、机构名称、会议届次都会变。

## 五、篇章骨架

### 5.1 活动方案九部分

```
一、关于"模拟联合国"        —— 活动简介 / 模联史 / 柳州模联现状（务实，含疫情后受挫与复兴）
二、大会选题介绍、阐释及展望  ★★★ 全篇灵魂
     1. 关于"思源"          —— 平台自我定义（受众、性质、宗旨）
     2. 大会选题介绍        —— 主题 + 议题清单 + 学术团队审核说明
     3. 选题阐释            —— 每议题三段式（历史演进 / 旨在 / 考量与价值）
     4. 选题展望            —— 主题的时空升华 + 青年落点（最长、最燃）
三、大会基本信息概要        —— 时间/会期/地点/规模/名称/主办/协办/承办/受众
四、大会参与人员与具体负责组织人员 —— 参会代表/观察员/志愿者定义 + 组委名单 + 培养模式论述
五、大会目的及意义          ★★ 双层结构
     1. 战略掣领            —— 宏观：联合国意义 → 中国担当 → 青年责任 → 柳州定位 → "起点"期许
     2. 战术精微            —— 微观：五小项（教育意义/批判性思维/沟通领导/了解国际组织/宣传意义）
六、大会基本情况及学术设计概述 —— 会场设置 / 议题 / 席位 / 日程
七、关于大会经费及预算      —— 费用说明 + 预算细表 + 申领/结余声明
八、大会议程                —— 三天时间表
九、联系我们                —— 总负责人 + 学术总负责人 + "请各位领导、老师批评指正！"
```

**第二部分与第五部分是蒙贤熠的"文字产能集中区"**——所有诗词、领导人引语、时代论述都往这两处堆。写其他部分可以快写过，这两部分必须慢写。

**第五部分"战略掣领／战术精微"的对照结构**是蒙贤熠的原创框架：

- **战略掣领**（写"为什么办"）：安南引语 → 中国成就（双碳/巴黎协定/疫后增长）→ 二十大报告 → "大国担当" → 青年不可旁贷 → 柳州区位 → 期许成为"起点"
- **战术精微**（写"办成了有什么用"）：先引四字箴言（"功崇惟志，业广惟勤；合抱之木，生于毫末；以人为本，终致广大"）→ 平台定位 → 五个小项 → 总而言之收束

### 5.2 邀请函五段式

```
① 开篇祝语 + 称呼
   "尊敬的……：顺颂时祺！" / "展信佳！" / "见字如晤，佳想安善！"
   → 紧接时令节气描写（仲春/深秋/雨水/谷雨/八月/一月）
   → 宣布大会信息 + 正式邀请

② 承蒙与致谢 + 往届回顾
   → "承蒙大家的厚爱与支持……"
   → 上一届的成绩、收到的评价、收到的批评
   → "正是有了诸位的共同努力，思源模联才得以走到今天"

③ 时代背景与议题预告  ★
   → 一个时代判断段落
   → 本届主题与各会场议题的具体介绍（每议题一段，写清"要探讨什么"）
   → 用"与……同频共振""将思想溯洄至历史的长河"这类句式抬升

④ 主题升华 + 号召青年
   → "作为模联人，作为新一代的青年，我们的目光从不局限于眼前……"
   → "让我们以开放的心态，从细致关怀的人文视角，共同推动全球治理体系的完善与发展"

⑤ 收束 + 落款
   → "于此……之时邀您共襄盛举……" / "敬请光临，期待您的智慧与热情！"
   → 落款：大会组委会 + 年份
```

**注意**：邀请函比致辞多一层"往届回顾与致谢"（第②段），致辞没有这一段。

### 5.3 秘书长致辞五段式

```
① 称呼与自谦
   "各位尊敬的模联同仁：大家好。"
   → "对于此次出任……的秘书长，我深感荣幸。"
   → 感恩致谢（三层：模联同仁 / 领导老师 / 组委全体）

② 时代坐标  ★★
   → 用"回望这一年/这半年"起笔
   → 上一届到本届的时间与世事变迁
   → 黑天鹅、百年未有之大变局、全球南方崛起
   → 引领导人论述 + 引用本届主题句

③ 往届传承与本届突破
   → 逐届回顾主题：第一届关注……，第二届聚焦……，第三届以……为线……
   → 本届的会场安排与创新点
   → "时代视角、学术本位和人文情怀将是我们永恒的核心"

④ 引证密集段  ★★★
   → 领导人论述（国家层面）
   → 青年寄语（"未来属于青年，希望寄予青年"）
   → 地方指示（"解放思想，创新求变，向海图强，开放发展"）
   → 三句诗词连缀（蒙贤熠的标志性手法，见 02-文风基因.md）

⑤ 收束 + 落款
   → "期待与诸位在……的柳州相见与重逢"
   → "愿吾等联合国之子民，为更美好之世界而联合"
   → 落款：大会秘书长 蒙贤熠 + 日期
```

**致辞与邀请函的三个区别**：
1. 致辞有"往届传承与本届突破"（第③段），邀请函无
2. 致辞的第④段是三句诗词连缀的密集引证，邀请函无
3. 致辞有署名与日期，邀请函署机构不署人

## 七、自查问题（交稿前逐条回答）

1. 主题回应的是哪一件正在发生的事？答不上来 → 主题是空的，重做。
2. 主题的落点人群是谁？给了什么具体行动？答不上来 → 缺"青年回扣"，重写末段。
3. 每一个会场议题，是否都用"区别于……区别在于……视角的X使得……"讲清了机制价值？缺 → 补第（3）段。
4. 文中所有引文是否都实际检索到并标注了来源与年份？有凭记忆写的 → 立刻检索替换。
5. 是否出现了感叹号？出现 → 全部改为陈述句/分句。
6. 三层咬合（主题—时代—青年）是否真的咬住了？还是各说各话？
7. 末段是否落到了具体的青年行动上？
