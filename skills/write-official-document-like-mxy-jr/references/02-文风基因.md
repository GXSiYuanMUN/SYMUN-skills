# 板块二：文风基因

本文件回答"怎么说话"。内容结构对应 `01-写作能力.md`。

---

## 一、语气定位：有节制的激情

蒙贤熠的稿子情绪浓度很高，但**没有一个感叹号**。他的激情全部由三样东西承载：

1. **动词的力度** —— "吹响""奠基""点燃""席卷""赓续""挺膺""奔赴山海""追光逐焰"
2. **意象的密度** —— 节气、古典意象、地缘意象密集交替
3. **排比的结构** —— 三分、四分、六分的排比层层叠加

**诊断口诀**：
> 读起来"热"，但一个"！"都没有。如果读到"！"了，说明情绪溢出了控制，句子结构还没承载住它——回去改动词和意象，别改标点。

**三个层次的语气强度**（不同体裁要调档）：

| 体裁 | 强度 | 标志 |
|---|---|---|
| 活动方案（第二、五部分） | 最高 | "赓续""挺膺担当""为更美好之世界而联合" |
| 秘书长致辞 | 高 | 三句诗词连缀 + 领导人论述 |
| 邀请函 | 中高 | 时令起兴 + "共襄盛举" |
| 背景文件 | 中 | 学术陈述，去掉一切抒情 |
| 通告 | 低 | 表格化，节奏快，诗化引用减量到 0–1 处 |

## 二、句法节奏

### 2.1 长短句配比

蒙贤熠的段落是**"长句铺陈 → 中句转折 → 短句收束"**的三段式，一个自然段里必有 1–2 个 15 字以内的短句。

典型段落（第六届方案·选题展望）：

> 1991 年 12 月 25 日，红旗从克里姆林宫上空黯然降下。"冷战"结束，雅尔塔体系终结，世界进入"一超多强"时代。**但 2026 年的今天，美国的颓态已开始显现，旧的世界秩序亟需重构。**世界变乱交织，丛林法则、单边主义大行其道……

长句负责气势，短句负责转折与判断。

### 2.2 四字格密度

**每 200 字至少出现 4–6 个四字短语**，这是蒙贤熠文体最显著的节奏指纹。

高频四字格（可直接取用）：
- 时代类：百年未有之大变局、波澜壮阔、风雨兼程、沧桑巨变、浩荡前行、激流勇进
- 困局类：波诡云谲、错综复杂、盘根错节、危如累卵、举步维艰
- 品格类：政治过硬、素质全面、踔厉奋发、勇毅前行、笃行不怠
- 结构类：共商共建共享、行稳致远、标本兼治、固本培元
- 成绩类：举世瞩目、成就斐然、硕果累累、气象万千

**注意**：四字格必须**嵌在长句内部**，不能单独成段、不能连排成列表。

### 2.3 三分句式（蒙贤熠的签名结构）

几乎每一段论述都由三个层次的三分构成：

- 三重困境：`发展中国家制造业薄弱、发达国家贸易壁垒高筑、后疫情时代经济复苏乏力`
- 三项使命：`坚定"四个自信"、更好地规划人生航向`（两项）→ 常见三项：`厚植家国情怀、关注国家未来发展、心系人类前途命运`
- 三种品质：`坚定、开放、包容` / `高平台、宽视野、多领域`
- 三重责任：`以人类前途为怀、以各国福祉为念`

**操作**：写完一段，回头看能否把某组并列项补成三项或四项。蒙贤熠极少只写两项。

### 2.4 转折与递进的固定搭配

| 功能 | 蒙贤熠的固定写法 |
|---|---|
| 从描述转向判断 | "但"，"然而"，"而"，"尽管如此" |
| 从宏观转向具体 | "具体而言"，"更值得关注的是"，"尤其值得注意的是" |
| 从问题转向方案 | "因而"，"因此"，"正因如此"，"由此" |
| 从外国转到中国 | "中国作为……"，"我国正持续深入……"，"作为中华民族伟大复兴的中坚力量" |
| 从时代转到青年 | "作为新时代中国青年"，"当代青年"，"青年一代"，"广大青年" |
| 从国家转到地方 | "柳州位于国家……枢纽地带"，"广西作为……关键平台" |

### 2.5 关联词偏好

**高频使用**：因而、因此、由此、正因如此、与此同时、不仅……更……、无论……还是……、既……又……、尽管……但……、无论从……还是从……都可以得出结论

**低频使用 / 避免**：首先其次最后、综上所述、除此之外、值得注意的是、总而言之（这个可以用，但只用于段末收束一次）

## 三、意象系统

意象是蒙贤熠文体最容易辨识、也最难伪造的部分。按类别取用：

### 3.1 时令节气类（蒙贤熠几乎每篇必用）

**这是他最独特的开篇装置。** 直接写节令名，不做解释。

| 时令 | 用法示例 |
|---|---|
| 雨水 | "现在正是二十四节气中'雨水'节气的一候时节，万物即将复苏" |
| 谷雨 | "此刻正是二十四节气中'谷雨'节气的一候时节，春意盎然" |
| 深秋 | "秋风萧瑟，落叶纷飞，深秋的韵味已悄然铺满大地" |
| 仲春 | "仲春均天，顺颂时宜" |
| 八月 | "八月，是夏末的余韵与初秋的序曲交织的时刻" |

**配套短语**：
- 春：`春意盎然`、`万物复苏`、`春回大地`、`江春入旧年的首缕晨曦`
- 夏：`万木葱茏`、`蝉噪林逾静`、`青葵倾露`
- 秋：`秋风萧瑟`、`金秋硕果满枝头`、`层林尽染`、`最是橙黄橘绿时`
- 冬：`岁序更新`、`寒暑不息，步履不止`

### 3.2 古典意象类（致辞中的三句连缀，见第四节）

常用：
- `莫听穿林打叶声，何妨吟啸且徐行` —— 不畏风雨、从容向前
- `千磨万击还坚劲，任尔东西南北风` —— 意志坚定、不改初心
- `长风破浪会有时，直挂云帆济沧海` —— 展望未来
- `为君持酒劝斜阳，且向花间留晚照` —— 惜时、珍重
- `日月忽其不淹兮，春与秋其代序` —— 时间流转
- `江山留胜迹，我辈复登临` —— 承继前人
- `东有启明，西有长庚` —— 志同道合、并行不悖
- `长松卧壑困风霜，时来屹立扶明堂` —— 蓄势待发
- `花开占得春光早，雪缀云装万萼轻` —— 早春生机
- `梦虽遥，追则能达；愿虽艰，持则可圆` —— 信念（习近平新年贺词）

> 📌 以上均出自蒙贤熠本人手笔的文本。第五届邀请函（罗立茜）中的「一年好景君须记」「生逢盛世而不负盛世」等句**不属此列**，已剔除。
- `惟其艰巨，所以伟大；惟其艰巨，更显荣光` —— 奋斗的价值

### 3.3 地缘与家国类

- `龙城`（柳州别称，用于邀请函结尾"夏日的龙城"）
- `柳州位于国家"北部湾战略"枢纽地带`
- `广西作为"中国——东盟"交流与合作的关键平台`
- `平陆运河的建设将为广西未来 30 年乃至更远的一段时期的发展奠定新的基础`
- `八桂大地`、`八桂青年`、`桂籍学子`
- `壮族自治区`、`自治区副中心城市`

### 3.4 思源专属意象（本组织专属，必须用）

| 意象 | 含义 | 用法 |
|---|---|---|
| **源** | 饮水思源、寻根 | "思源"二字本身即"思其源" |
| **火种** | 传承、传递 | 蒙贤熠另有《火种计划》，"谨以此书致敬那些为模拟联合国事业做出贡献的前辈们" |
| **种子/播种** | 办会的育人隐喻 | "与大家共同播种希望，收获未来" |
| **吾等联合国之子民** | 入会誓词 | **每篇致辞/邀请函的倒数第二句必须出现**，原句："愿吾等联合国之子民，为更美好之世界而联合" |
| **始于模联，不止于书案** | 组织定位 | "为广西中学生提供一个'始于模联，不止于书案'的、以学术为核心的多元平台" |
| **传帮带 / 泉涌不竭，人才辈出** | 传承机制 | "有利于形成'传帮带'的发展模式和'泉涌不竭，人才辈出'的发展格局" |
| **自己人、家门口** | 地方亲近感 | "搭建'自己人''家门口'的高品质、零门槛的社会实践平台" |
| **赋能与提质** | 教育价值 | "思源模联将致力于赋能提质素质教育" |

## 四、引证方式：四级引证表

蒙贤熠的引证是有层级的，**不是随便堆权威**。按重要性排序：

### 第一级：领导人论述（最高级，用于方案第二、五部分与致辞第④段）

**写法三要素**：会议/场合 + 原文引号 + 落点。
```
{会议或报告全称}中{指出/强调/勉励}，"{原文}"
```
实证：
> 习近平总书记在党的二十大报告中殷切勉励青年群体，指出新时代青年是推进中国式现代化建设的关键力量，应通过青年之声向国际社会传播中国倡导的和平理念与人类命运共同体构想……

**常用落点**：
- 二十大报告 → 青年使命、文明交流超越文明隔阂
- 二十大报告 → "以文明交流超越文明隔阂，以文明互鉴超越文明冲突，以文明共存超越文明优越"
- 习近平广西视察指示 → "解放思想，创新求变，向海图强，开放发展"（每届必用，是思源的地域锚）
- "未来属于青年，希望寄予青年"（每届必用）
- 新年贺词 → "梦虽遥，追则能达；愿虽艰，持则可圆"
- 二十届四中全会"十五五"规划建议 → 第五、六届主题的直接依据

### 第二级：外长记者会（高频，用于标注"当下时点"）

固定句式：
> {今年/去年}{三月/四月}，王毅外长在第十四届全国人大{二/三/四}次会议外交主题记者会上{表示/指出}，"……"

实证：
> 王毅外长在 2026 年的慕尼黑安全会议上发表主题演讲时指出，"人类风雨兼程走到今天，同舟共济才是正确选择。我们应当通过改革完善全球治理，校正这艘历史巨轮的正确航向。"

### 第三级：国际组织与秘书长（用于抬升问题层次）

- 安南："一个国家的政治稳定离不开理性思考的公民……对下一代的教育将会是未来实现全球和平与繁荣的至关重要的因素。"（**历届反复使用，是思源的固定开场引语**）
- 安南（致模联信）："联合国依靠世界上每个人的努力而存在，尤其是像你们这样的青年，这个世界不久将会是你们的。"
- 古特雷斯："精准扶贫方略是帮助最贫困人口、实现联合国2030年可持续发展议程设定的宏伟目标的唯一途径。"
- 毛泽东（莫斯科讲话，1957）："世界是你们的，也是我们的，但是归根结底是你们的。你们青年人朝气蓬勃……好像早晨八、九点钟的太阳。希望寄托在你们身上。"

### 第四级：经典文辞与诗词（用于抒情层）

见第 3.2 节。**致辞中三句连缀是蒙贤熠的标志性手法**：

```
第一句：写困境中的从容      →"莫听穿林打叶声，何妨吟啸且徐行"
第二句：写意志的坚定        →"千磨万击还坚劲，任尔东西南北风"
第三句：写对未来的展望      →"长风破浪会有时，直挂云帆济沧海"
```
三句之间用空行分段，句前常配"当……之际""在这个……的时代"的时间状语。

### 引证纪律

1. **引原话必须加引号**，不转述不留出处
2. **领导人姓名与职务要写全**："习近平总书记"、"中共中央政治局委员、外交部长王毅"
3. **会议届次要写准**："第十四届全国人大三次会议外交主题记者会"
4. **不引二手转述**。宁可少引一句，不可引错一句。
5. **每篇引证数量控制在 3–6 处**。超过 6 处会变成"权威展览"。

## 五、高频句式模板库

以下句式骨架可直接套用（`{}` 为填充位）：

### 5.1 开篇

```
{时令节气描写}，我们荣幸地宣布，{大会全名}将于{时间}在{地点}举行。在此，我们诚挚地邀请{对象}参与本次大会。
```

```
尊敬的{对象}：{祝语}！{时令}。我们荣幸地宣布……
```

### 5.2 往届致谢

```
承蒙大家的厚爱与支持，{上届大会名称}获得了广泛的好评和超乎想象的成功，我们深深感激大家的肯定与鼓励，同时也虚心接受所有的批评。
```

```
{时间}年，{活动名}在{地点}顺利谢幕，与大家共度了{届次}会期的美好时光。{往届场景}，如今来到了{本届}即将拉开的帷幕之前。
```

### 5.3 时代判断

```
{时间}年{是/即将迎来}{周年/关键节点}，也是{另一事件}。{领袖}指出，{原话}。事实证明，{判断}。
```

```
回望{时间段}，"黑天鹅"翅膀的阴影仍然笼罩着这颗蓝色的星球：{危机1}、{危机2}、{危机3}……但低潮之后的曙光业已显现：{曙光1}、{曙光2}……
```

### 5.4 议题阐释（第（3）段"考量与价值"专用句式）

```
在{机制}的框架下，聚焦"{议题}"，具有{考量与独特的教育价值/深远的战略考量}。

区别于{传统做法}，本次会议的参与者并非{旧状态}，而是{新状态}。视角的{下沉/前移/上移}使得讨论不再局限于{旧范围}，而是切实聚焦于"{具体问题一}""{具体问题二}""{具体问题三}"以及"{具体问题四}"等根本性问题。代表们得以暂时搁置{国家层面的利益纠葛}，转而{新的共同议题}，通过{谈判方式}，共同探索{新路径}。
```

### 5.5 青年落点

```
本次大会期望与{地区}青年一道，以{平台}为独特平台，让青年在学习{两会精神/时政}、关注祖国发展的过程中，{深化认知}，进一步认识中国在世界中的位置，坚定"四个自信"、更好地规划人生航向。
```

```
我们期待以此次大会为契机，让更多的{八桂青年}将个人发展与祖国的前途命运紧密结合起来，以人类前途为怀、以各国福祉为念，成为国际合作的践行者、文明互鉴的推动者和人类命运共同体的建设者。
```

### 5.6 结尾

```
期待{时间}在{地点}与诸位相遇与重逢，"愿吾等联合国之子民，为更美好之世界而联合"。
```

```
{大会全称}期待与你共赴{季节}的{盛会/盛宴}！
```

### 5.7 落款格式

```
大会秘书长  蒙贤熠
{YYYY}年{M}月{D}日
```

```
{大会全称}组委会
{YYYY}年{M}月
```

## 六、禁忌清单（比"写什么"更重要）

### 🔴 绝对禁止

| 禁止 | 说明 |
|---|---|
| **感叹号** | 蒙贤熠原稿通篇零感叹号。这是文风的第一道红线 |
| **网络用语** | "绝绝子""yyds""打卡""破防"" emo""666" |
| **口水词** | "非常好""特别棒""超级""巨""十分十分""简直是" |
| **空洞形容词堆砌** | "极其""无比""非常非常"连用 |
| **AI 味连接词** | "首先……其次……最后……""总而言之总而言之"、过多"Moreover""Furthermore" |
| **英文缩写当主语** | 写"UN 指出"而非"联合国指出"；写"MUN 社区"而非"模联社区" |
| **党八股套话连用** | "在……的坚强领导下""具有重大、深远的意义" 单独出现无实质内容 |
| **翻译腔** | "基于……的考虑""做出决定""这不仅仅是……更是一个……"连用三次以上 |
| **未经检索的引文** | 凭印象写领导人讲话原文。检索不到就换一句或删掉 |
| **情绪符号** | emoji、颜文字、"！！！" |

### 🟡 慎用（不可滥用）

| 慎用 | 说明 |
|---|---|
| 四字格 | 每 200 字 4–6 个足够，多了会显得堆砌 |
| "百年未有之大变局" | 历届都用过，但**同篇只用一次** |
| 领导人引语 | 同一人最多引 2 处；一篇 3–6 处为上限 |
| 排比 | 连续 3 个排比后要换句式，否则读者疲劳 |
| 诗词 | 一篇最多 3 句，且必须有具体落点，不能纯装饰 |
| "以人类前途为怀、以各国福祉为念" | 是思源专属套语，一篇一次 |
| 数字罗列 | 连续超过 5 个数字会让读者麻木，分散到不同段落 |

### 🟢 必须做到

| 做到 | 说明 |
|---|---|
| **动词有力** | 用"吹响""奠基""赓续""挺膺""奔赴""追光""踏浪"，不用"进行""开展""举办""实现" |
